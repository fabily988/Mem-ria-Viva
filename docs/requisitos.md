♡ Requisitos Funcionais ♡

- A plataforma vai permitir o cadastro de pacientes
- Vai permitir o cadastro de cuidadores
- Vai permitir que pacientes e cuidadores realizem login utilizando credenciais de acesso
- Vai mostrar uma página inicial pro o paciente, contendo informações importantes da rotina diária
- Vai permitir a visualização da agenda diária do paciente
- Vai permitir ao cuidador cadastrar, editar e excluir consultas do paciente
- Vai permitir ao cuidador cadastrar medicamentos, informando nome, dosagem, horário e observações
- Vai mostrar lembretes de medicamentos ao paciente nos horários cadastrados
- Vai permitir o cadastro de familiares contendo foto, nome, grau de parentesco e contato
- Vai mostrar pro paciente um album da família pra visualização das informações cadastradas
- Vai permitir o cadastro de memórias especiais contendo foto, data e descrição
- Vai permitir ao paciente ver as memórias especiais cadastradas
- Vai mostrar exercícios de estimulação cognitiva ao paciente
- Vai mostrar frases motivacionais na página inicial do paciente
- Vai permitir o cadastro de contatos de emergência 
- Vai mostrar ao paciente um botão "Preciso de ajuda"
- Ao apertar o botão "Preciso de ajuda", o sistema vai enviar uma mensagem ao contato de emergência 
- A plataforma vai permitir ao cuidador acompanhar informações gerais do paciente por meio de um painel de acompanhamento
- Vai permitir ao cuidador editar ou excluir os dados cadastrados no sistema
- O sistema vai permitir a atualização dos dados cadastrais de pacientes e cuidadores

♡ Requisitos Não Funcionais ♡

- A plataforma vai ter uma interface intuitiva e de fácil uso
- Usar fontes legíveis e de tamanho adequado pra facilitar a leitura dos usuários
- Vai ter botões e elementos visuais de tamanho adequado pra facilitar a interação
- Vai ser responsivo (permitindo acesso por computadores, tablets e celulares)
- Vai armazenar as senhas dos usuários de forma segura 
- Vai garantir a privacidade e a proteção dos dados dos usuários 
- Vai controlar o acesso às funcionalidades de acordo com o perfil do usuário (paciente ou cuidador)
- Vai ser desenvolvido permitindo futuras expansões e manutenções
- Vai ter código-fonte organizado e documentado
- Vai ser compatível com os principais navegadores web
- Vai proporcionar uma experiência de uso acessível, organizada e acolhedora pras pessoas com Alzheimer 
- Ele não substitui o acompanhamento médico ou profissional especializado, sendo destinado exclusivamente ao apoio da rotina de pacientes e cuidadores
